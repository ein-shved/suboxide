# Requirements

## REQ-001: Music server

suboxide must serve as a music server.

### Scenario: Listen remotely

- WHEN a user wants to listen to music remotely
- THEN the user can connect to suboxide and listen to music, similarly to using Navidrome

### Scenario: Accept a limited feature set

- WHEN suboxide lacks a Navidrome capability that no acceptance scenario explicitly requires
- THEN that omission is acceptable; full Navidrome feature parity is unnecessary
